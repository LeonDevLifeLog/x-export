# Chrome Web Store MVP 发布基线

目标：交付可提交审核的最小 Chrome MV3 扩展与完整提交材料。实际提交、账户付费、商店审核和上线属于发布操作，不能用本地验证代替。

## 范围

- 复用当前浏览器已登录的 X 页面，读取单条帖子、长文及用户手动选入的同作者已加载内容。
- Markdown、独立 HTML、通过 Chrome 原生打印保存 PDF。三种阅读主题与内容开关。
- 英文和简体中文：manifest、弹窗、预览、错误与进度、帮助和隐私页，以及文档生成的辅助文字。正文、作者和用户标题不翻译。自动跟随 Chrome 界面语言，可手动切换；其他语言回退英文。
- 必需权限仅 activeTab / scripting / storage / downloads。图片 CDN 用 optional_host_permissions，在 HTML/PDF 嵌图时按用户操作申请；拒绝后仍导出文字并注明图片未嵌入。
- 无服务器、账号系统、付费、埋点、远程脚本、自动滚动或 X 私有 API。

## 验收

1. 本地语法/结构检查、单元测试、隔离 Chrome 扩展浏览器场景通过；新增场景覆盖双语、权限拒绝、数据清理。
2. 安装包 manifest 位于 ZIP 根目录，包含双语目录和运行文件，不含测试、开发依赖、真实用户样张或商店材料。构建可复现、文件清单与 SHA-256 可检查。
3. 商店素材：128px 图标、440×280 小宣传图、每种语言的 1280×800 实际界面截图；提供可选 1400×560 大宣传图。素材使用原创示例，不暴露登录账号或他人内容。
4. 提交文案：双语描述、单一用途、逐项权限理由、远程代码/数据用途声明、审核员测试步骤、隐私政策和支持页。
5. 公开隐私政策 URL 与开发者账户状态属于外部前提；有未提供的字段必须明确标出，不能编造为已发布。

## 发布前人工验收

实际 Chrome 工具栏触发 activeTab、首次可选图片权限对话框（允许/拒绝/撤销）、系统保存与打印窗口，以及当前登录 X 的真实帖子与长文。隔离测试会说明使用的替代条件。商店文案须保留“PDF 通过打印保存”与“只读取已加载内容”的实际限制。
