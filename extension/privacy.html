X Export · Privacy policy

Effective: 13 October 2026 · Version 1.1.0

What the extension does

X Export, maintained by LeonDevLifeLog, is an independent Chrome extension that turns X posts and articles into Markdown, standalone HTML, or PDF through Chrome printing. It is not affiliated with X Corp. The only purpose of processing page information is to provide the export you request.

Information handled

When you click Read current post, the extension reads already-loaded content on your current X page: post/article text, author display names and handles, publication dates, source URLs, quoted text, and image references. You choose which loaded posts are included. The active page URL is checked to enable the feature. The extension does not read your browsing history, direct messages, passwords, authentication cookies, access tokens, payment details or account settings.

Storage and retention

Structured documents, your edited title and selected posts are temporarily stored in Chrome extension session storage on your device. Chrome clears that storage when the browser session ends or the extension is disabled, reloaded or updated. Records older than 24 hours are removed the next time you read a post; this is not a scheduled deletion. Layout and language preferences remain in extension local storage until you uninstall the extension or clear its storage. No Chrome Sync storage is used.

Network requests and sharing

There is no developer backend, analytics, advertising or telemetry. Document text, author information and source URLs are not uploaded to the developer. The preview can load selected images from X’s image CDN (pbs.twimg.com). To embed images in HTML/PDF, the extension requests optional permission for that CDN and fetches those image URLs over HTTPS, without authentication credentials or a referrer. X’s CDN necessarily receives the image URL and ordinary network information such as your IP address, and its own privacy practices apply. This image permission can be declined or revoked. Failed or denied embeds produce original-image links instead.

Opening an original-post, original-image or content link visits the destination website under its own privacy practices. Exported Markdown contains remote image URLs, which your Markdown reader may load. Successfully embedded images in standalone HTML/PDF do not need a network request to read. Sharing or uploading an exported file is entirely your choice; it may contain personal or non-public information visible to your X account.

Control and deletion

Use Help & privacy → Clear temporary documents to remove captured documents and invalidate their open previews. Close Chrome to end session storage. Uninstall the extension to remove its local preferences. Downloaded files are separate and are not deleted automatically; delete or manage them using your file manager. Revoke the optional image permission in Chrome’s extension site-access settings. The extension does not bypass X access controls or retrieve unloaded content.

Limited Use

X Export uses handled information only to provide its single, user-requested export feature. It does not sell information, use it for advertising, transfer it to data brokers, or use it to determine creditworthiness or lending eligibility. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. All executable code is packaged with the extension; no remote code is loaded.

Contact and updates

After release, contact the developer using the support contact on the X Export Chrome Web Store listing. Do not send passwords, cookies, tokens or private exported documents. This policy will be updated when data handling changes, with an updated effective date. A public support contact and publicly accessible policy URL must be supplied with the store submission.

扩展的用途

X Export 由 LeonDevLifeLog 维护，是将 X 帖子和长文导出为 Markdown、独立 HTML，或通过 Chrome 打印保存 PDF 的独立扩展，与 X Corp. 无关联。处理页面信息的唯一用途是完成你主动要求的导出。

处理哪些信息

点击“读取当前发文”后，扩展读取当前 X 页面已经加载的正文、作者名称和账号、发布日期、来源 URL、引用文字和图片引用。由你选择要包含的已加载发文。扩展检查当前页面 URL 以启用功能，不读取浏览历史、私信、密码、认证 Cookie、访问令牌、支付信息或账号设置。

存储与保留时间

结构化文档、你修改的标题和选中的发文暂存在设备上的 Chrome 扩展会话存储。浏览器会话结束，或扩展被禁用、重新加载、更新时，Chrome 会清除该存储。超过 24 小时的记录在下次读取发文时删除，并非定时删除。排版和语言偏好保存在扩展本地存储，直到卸载扩展或清除其存储；不使用 Chrome Sync。

网络请求与分享

没有开发者后端、分析埋点、广告或遥测。正文、作者信息和来源 URL 不上传开发者。预览可能从 X 图片 CDN（pbs.twimg.com）加载所选配图。为在 HTML/PDF 嵌入图片，扩展按需请求该 CDN 的可选权限，通过 HTTPS 读取图片 URL，不携带认证凭据或来源 referrer。X CDN 必然会收到图片 URL 和 IP 地址等正常网络信息，其自身隐私规则适用。可以拒绝或撤销该图片权限，拒绝或失败时改为保留原图链接。

打开原文、原图或内容中的链接，会访问对应网站并适用该网站的隐私规则。Markdown 保留远程图片 URL，你的阅读器可能加载这些图片。HTML/PDF 中成功嵌入的图片在阅读时无需联网。是否分享或上传导出文件由你决定，文件可能包含当前 X 账号可见的个人或非公开信息。

控制与删除

通过“帮助与隐私 → 清除临时文档”删除已读取文档，同时使其已打开的预览失效。关闭 Chrome 清除会话存储；卸载扩展清除本机偏好。已下载文件不会自动删除，请在文件管理器中处理。可在 Chrome 扩展的网站访问设置中撤销图片权限。扩展不绕过 X 的访问控制，也不获取未加载内容。

有限使用

X Export 仅将信息用于用户主动发起的单一导出功能。不出售信息、不用于广告、不传给数据经纪商，也不用于决定信用或贷款资格。从 Google API 获取的信息遵守 Chrome 应用商店用户数据政策，包括 Limited Use 要求。所有可执行代码均随扩展打包，不加载远程代码。

联系与更新

发布后通过 X Export 的 Chrome 应用商店条目所列支持联系方式联系开发者。请勿发送密码、Cookie、令牌或私密导出文件。数据处理方式变化时会更新本政策与生效日期。商店提交时需提供公开支持联系方式和可公开访问的隐私政策 URL。
