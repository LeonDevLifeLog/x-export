# X Export 1.1.0 · Chrome Web Store MVP

本版完成扩展优化和提交材料准备。政策及支持页面已发布到 GitHub Pages，支持联系方式采用公开仓库的 GitHub Issues。2026-10-13 发布者提供真实商店条目地址，并确认审核中；README 与官网首页已加入该链接，当前不宣称商店批准。

## 用户可见变化

- 英文与简体中文界面，可跟随 Chrome 或手动切换；正文、作者和修改后的标题不翻译。日期、数字和文档辅助文字按界面语言显示。
- X 图片 CDN 访问改为按需可选权限。Markdown 不请求该权限；HTML/PDF 拒绝授权仍能导出文字与原图链接。
- 增加帮助、随包双语隐私政策与临时文档清理。清理使已有预览失效，保留排版/语言偏好和下载文件。
- 弹窗新增“关于”入口，帮助页中的开发者介绍提供 LeonDevLifeLog 的 GitHub 主页与项目仓库链接，中英文均可用。
- 调整预览页操作顺序，让导出按钮先于长设置列表可见；英文弹窗符合 Chrome 的尺寸限制。

## 发行与材料

- 商店 ZIP 根目录直接包含 manifest。仅打包运行文件；固定文件顺序和时间戳，重复构建的扩展 ZIP SHA-256 一致。
- 中英文长描述、逐项权限理由、数据处理声明、审核测试说明与可托管页面。
- 两种语言各 5 张实际界面截图，128px 图标、440×280 小宣传图、可选 1400×560 大宣传图，全部使用原创示例内容。
- store:check 检查源码/ZIP 一致性、权限、语言、图片尺寸、截图来源摘要和网站内链。完整移交包另含扩展 ZIP、检查报告与 SHA256SUMS。

## 验证结果

语法/入口检查通过，9 项单元检查与 19 个隔离 Chrome 浏览器场景通过，无 JavaScript 错误。实际 MD/HTML 下载、英文输出、离线嵌图、权限拒绝恢复、双语保持原文、375px 布局、临时数据清理均覆盖。PDF 样例为 2 页及 6 页 A4，50 段分页文本完整；实际查看了 PDF 渲染。

浏览器自动化使用合成 X 页面和初版真实 DOM 回放，并替代了 activeTab 工具栏手势、图片权限和原生保存/打印窗口。另在隔离的 Chrome for Testing 中加载未修改的发行扩展，实际通过工具栏读取、原生权限拒绝/允许、Chrome 打印和 macOS PDF 保存；拒绝时的链接回退与允许后的嵌图均由下载文件确认。原生 PDF 为 1 页 A4，中文与 emoji 正文完整且不含编辑界面。

原生验证仍使用构造页面和图片，MD/HTML 保存窗口、权限撤销后重试及用户个人 Chrome 的线上完整导出尚未验证。完整证据边界见项目 VERIFICATION.md。
