Help with your export.

Read a complete post

Sign in to X in Chrome. Open the post detail or complete article, expand Show more, wait for the body to load, and click the extension icon again. Other loaded posts by the same author must be reviewed before including them.

Images and offline reading

HTML/PDF image embedding needs optional permission for pbs.twimg.com. Allow it when exporting; if denied or an image fails, the document keeps an original-image link. Markdown uses online image URLs. Videos and quoted-post images are not downloaded.

Save a PDF

Choose PDF and Export. In Chrome’s print dialog choose Save as PDF. Disable headers and footers; enable background graphics if wanted. The extension does not create a PDF download automatically.

Report a problem

Include the extension version, Chrome version, operating system, chosen format and a public X example URL. Describe the expected and actual result. Never send passwords, cookies, tokens or private exported content. X changes its page structure, so a new layout may require an extension update.

Delete temporary data

Open Help & privacy in the extension and click Clear temporary documents. Existing previews become unavailable. Close Chrome to clear session data; uninstall to remove local preferences. Manage downloaded files separately in your file manager.

导出帮助

读取失败时先确认当前 Chrome 已登录 X，打开帖子详情或长文全文、展开“显示更多”并等待加载，再点击扩展重新读取。同作者其他已加载发文需逐条核对后选入。

HTML/PDF 离线嵌图需允许 pbs.twimg.com 可选权限。拒绝或失败时保留原图链接；Markdown 使用在线图片 URL。视频和引用发文图片不下载。

导出 PDF 后，在 Chrome 打印窗口选择“保存为 PDF”，关闭页眉页脚，按需开启背景图形。扩展不会自动生成 PDF 下载。

反馈问题请提供扩展版本、Chrome 版本、操作系统、格式和公开 X 样例 URL，以及预期与实际结果。不要发送密码、Cookie、令牌或私密内容。X 页面结构变化可能需要兼容更新。

“帮助与隐私 → 清除临时文档”会使已有预览失效。关闭 Chrome 清除会话数据；卸载扩展移除偏好。已下载文件需在文件管理器单独处理。
